# WEBINARIOS

Centraliza tudo de cada webinário e aula ao vivo: briefing estratégico, copies de e-mail, disparos de WhatsApp, kit de aquecimento e leitura de resultado.

Um webinário é uma campanha inteira, não uma peça. Por isso ele ganha pasta própria em vez de virar arquivo solto dentro de `CAMPANHAS MENSAIS/`.

## Convenção de pastas

`Sigla do tema + Público + Mês-Ano`

```
WEBINARIOS/
└── SS Nutri Agosto-26/
    ├── [SS] Briefing Estrategico.md
    └── [SS] Copies E-mails.md
```

> **Atenção:** o separador entre mês e ano é hífen, não barra. Barra (`/`) é separador de diretório no sistema de arquivos e não pode existir em nome de pasta. `Agosto/26` viraria uma subpasta `Agosto` com um item `26` dentro.

## Convenção de arquivos

`[TAG] Tipo do documento.md`

A tag identifica o webinário e se repete em todos os arquivos da pasta, para achar rápido em busca global.

| Tag | Webinário |
|---|---|
| `[SS]` | MasterClass Social Selling Nutri |

## Documentos de uma pasta de webinário

| Arquivo | Conteúdo |
|---|---|
| `Briefing Estrategico` | Big Idea, público, narrativa, nomenclatura, infraestrutura, calendário, métricas e riscos. Fonte da verdade da campanha |
| `Copies E-mails` | Sequência completa de e-mails, com status por peça |
| `Copies WhatsApp` | Disparos 1x1 e kit de aquecimento do grupo (quando houver) |
| `Resultado` | Números medidos e decisão de GO/NO-GO (criado depois do evento) |

## Status de cada peça

`Rascunho` → `Aprovado` → `Disparado`

O status fica no cabeçalho de cada peça, nunca só no nome do arquivo.
