# CAMPANHAS MENSAIS

Centraliza toda a copy escrita, mês a mês. Serve para encontrar rápido, gerir o que está no ar e fazer variações depois em cima do que já foi produzido.

## Convenção de pastas

`AAAA-MM - Mês` — o prefixo com ano e número garante que as pastas ordenem sozinhas e não conflitem quando virar o ano.

```
CAMPANHAS MENSAIS/
├── 2026-07 - Julho/
├── 2026-08 - Agosto/
├── 2026-09 - Setembro/
├── 2026-10 - Outubro/
├── 2026-11 - Novembro/
└── 2026-12 - Dezembro/
```

## Convenção de arquivos

Um arquivo por peça:

`[TAG PRODUTO] Copy #nome | Pack-Mês.md`

Exemplo: `[WN] Copy Criativos B-roll VSL | Pack01-Julho.md`

Tags de produto: `[WN]` Webnutri · `[GCN]` Guia de Condutas · `[ANC]` Aceleração · `[MNC]` Master NC

> **Atenção:** o separador entre pack e mês é hífen, não barra. Barra (`/`) é separador de diretório no sistema de arquivos e não pode existir em nome de arquivo — `Pack01/Julho` viraria uma subpasta `Pack01` com um arquivo `Julho` dentro.

## O que cada arquivo deve ter

- **Status** (Rascunho / Aprovado / No ar / Pausado)
- **Produto, formato e destino** (para onde o clique vai)
- **Copy final** (headlines, legenda, roteiro — o que a peça pedir)
- **Notas de produção** (cenas, referências visuais, links de B-roll)
- **Histórico de variações**, quando houver

Copy antiga, anterior a esta organização, continua em `docs/copy-ads/`.
