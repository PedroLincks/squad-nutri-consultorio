# Playbook — Anúncios de Performance (Meta / Facebook / Instagram / TikTok / Google)

Objetivo: parar o scroll, gerar UM clique/ação. Copy curta, ângulo afiado. Lendas: Kennedy (oferta direta), Kern (autenticidade), Carlton (ângulo escondido), Schwartz (calibragem).

## Estrutura: Hook → Body → CTA

### HOOK (3 primeiros segundos — 80% do trabalho)
Tem que parar o polegar. Calibre pelo nível de consciência:
- **Inconsciente / Problema-aware:** dor específica, cenário reconhecível, pergunta provocativa, "POV", contraste visual.
- **Solução-aware:** resultado desejado + "sem [a dor]".
- **Produto/Mais-aware:** oferta/deal direto.

Tipos de hook que funcionam:
1. **Pergunta provocativa** que só o avatar responde "sim".
2. **Afirmação forte/contrária** que desafia a crença comum.
3. **Cena/POV** ("Você abre o consultório segunda e...").
4. **Dor nomeada** com especificidade.
5. **Mini-história** (primeira pessoa, real).
6. **Número/dado específico** ("Em 2 semanas, 14 nutris fizeram isso").

### BODY (desenvolvimento)
- Mantenha UMA ideia. Slippery slide: cada linha puxa a próxima.
- Estrutura útil em ad curto: **PAS** (Problema → Agita → Solve) ou **BAB** (Before → After → Bridge).
- Prova rápida (resultado específico, número, demonstração) — sem inventar.
- Conecte feature → benefício → payoff emocional.
- Parágrafos de 1-2 linhas. Quebras frequentes. Emojis se o tom permite.

### CTA (uma ação)
- Comando direto: "Clica no link e [resultado]", "Comenta [palavra]" (ManyChat), "Salva esse post".
- Um só CTA. Diga exatamente o que fazer e o que vai acontecer.

## Formatos
- **Vídeo (frontal/UGC/narrado):** entregue roteiro com timestamps + **notas de cena**. Hook nos 0-3s. Veja `vsl.md` para roteiros longos.
- **Imagem estática:** headline visual + copy de apoio + CTA.
- **Carrossel:** Slide 1 = hook visual + texto. Slides 2-8 = desenvolvimento (1 ideia por slide). Último = CTA. + legenda.

## Variações A/B
Ao pedir variações, mude **uma alavanca por vez**:
- Mesmo body, **hooks diferentes** (teste o que importa mais).
- Mesmo hook, **ângulos/Big Idea diferentes**.
- Níveis de consciência diferentes (público frio vs quente).
Numere as variações e rotule a alavanca testada.
